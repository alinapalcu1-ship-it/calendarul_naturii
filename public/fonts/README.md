# Fonturi locale

Nunito și Playfair Display, variante cu greutate variabilă, descărcate din depozitul oficial google/fonts. Sunt incluse local pentru a evita solicitările către furnizori externi la utilizarea aplicației. Diacriticele românești sunt incluse.

Surse:
- https://github.com/google/fonts/tree/main/ofl/nunito
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay
